# 🌐 TimeMouser — Personal Bio Link

Стильный, минималистичный сайт-визитка с эффектом **Glassmorphism**, интерактивными элементами и автоматическим отслеживанием онлайн-статуса Twitch / YouTube.

![GitHub Pages Status](https://img.shields.io/badge/Status-Online-brightgreen?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

---

## ✨ Особенности (Features)

* 🎨 **Glassmorphism UI** — современный стеклянный дизайн с адаптивной версткой.
* 🧲 **Интерактивные эффекты** — магнитный эффект карточек, динамический светильник при движении мыши и кастомный шлейф за курсором.
* 🔴 **Live-статусы** — автоматическая проверка прямых трансляций на Twitch и YouTube.
* 📲 **QR-код** — встроенный генератор QR-кода для быстрого перехода с мобильных устройств.
* 📋 **Быстрое копирование** — копирование Discord ID в один клик с всплывающим уведомлением (toast).

---

## 🛠 Технологии (Tech Stack)

* **HTML5 / CSS3** — разметка, CSS-переменные, Flexbox, CSS Grid и анимации.
* **JavaScript (ES6+)** — логика взаимодействия, работа с API и динамические эффекты.
* **Font Awesome / Lucide Icons** — векторные иконки.
